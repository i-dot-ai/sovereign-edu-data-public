# What a tool has to do

{: .in-short }
The twelve things a tutoring tool needs to do to take part, in plain words.

{: .outline }
This page is an outline. The headings and points below show what it will cover.

## The twelve requirements

- Grouped: naming the pupil, sessions, the records to send, the actions allowed, timestamps, and sending through the service.

## What could change

- Converting a tool's own records ourselves, so tools don't have to change how they record.
