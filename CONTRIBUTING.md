# How to comment

Anyone with a GitHub account can comment.

- **On a page:** use the comment box at the bottom of the page.
- **To suggest a wording change:** click "Suggest a change to this page" at the bottom of the page. GitHub will help you open a pull request with your edit.
- **For a bigger point:** [open an issue](https://github.com/i-dot-ai/sovereign-edu-data-public/issues/new?template=feedback.md).

Please keep comments about the ideas in the document. Don't share any personal data about pupils, teachers or anyone else.
