# Talking to the integration layer

{: .in-short }
Tools talk to the integration layer (the system that sits between schools and AI tutoring tools) through six functions, using a standard way for AI tools to call services (MCP).

{: .outline }
This page is an outline. The headings and points below show what it will cover.

## The six functions

- Get everything needed at the start of a session.
- Get records.
- Send records.
- Get the pupil's summary.
- Get materials.
- Get where a lesson sits in the curriculum.

## What classroom context contains

- The curriculum position, the school's materials, the pupil's summary and their recent sessions.
