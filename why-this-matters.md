# Why this matters

{: .in-short }
Tools start from scratch with every pupil, teachers' own materials aren't recognised, and a pupil's learning is lost when they change tool.

{: .outline }
This page is an outline. The headings and points below show what it will cover.

## Tools start from scratch

- A tool has no standard way to learn what a pupil already knows.
- It spends the first part of every session finding out, or guesses.

## Teachers' own materials

- Most of what teachers use isn't labelled with a lesson.
- We don't want teachers to label anything: the system should work with what they already use.

## Learning gets lost

- When a school changes supplier, or a pupil uses a different tool, what was learned about them is left behind.

## Why a shared approach

- One translation per tool or school, instead of one for every pair.
- No single company owns the picture of a pupil.
