# In one page

{: .in-short }
The problem, the idea, what we've shown, and what we'd like your views on.

{: .outline }
This page is an outline. The headings and points below show what it will cover.

## The problem

- AI tutoring tools start with every pupil knowing nothing about them: what they've been taught, from what materials, and where it fits in the curriculum.
- What a tool learns about a pupil stays inside that tool. The next tool, or the school, can't use it.

## The idea

- A shared data layer between tutoring tools and a school's systems.
- Everything is linked to one shared map of the curriculum, so any tool can understand any other tool's records.
- Tools ask for what they need before a session, and hand back what they saw after it.

## What we've shown so far

- A working proof of concept, with synthetic pupils only.
- A tool that had never met a pupil got the context it needed in one request; a second tool picked up where the first left off.
- A teacher's own unlabelled quiz was matched to the right lesson automatically.

- Anything that's unclear, missing or wrong.
