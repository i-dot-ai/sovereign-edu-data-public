# In one page

{: .in-short }
The problem, the idea, what we've shown, and what we'd like your views on.

## The problem

AI tutoring tools start every pupil from nothing.
They don't know what the pupil has been taught, from which materials, or where it fits in the curriculum.

And what a tool learns about a pupil stays inside that tool.
The next tool, or the school, can't use it.

## The idea

An **integration layer**: a system that sits between schools and AI tutoring tools.

- Everything in it is linked to one shared map of the curriculum, so any tool can understand any other tool's records.
- Before a session, a tool asks it what it should know about the pupil and the lesson.
- After a session, the tool sends back what happened and what the pupil understood.

## What we've shown so far

We built a proof of concept, using made-up pupils only.

- A tool that had never met a pupil got everything it needed in one request.
- A second tool picked up where the first left off.
- A teacher's own quiz, with no label on it, was matched to the right lesson automatically.
