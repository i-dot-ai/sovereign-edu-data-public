# Describing and placing material

{: .in-short }
An AI writes a short description of any piece of teaching material, so it can be matched to the right lesson on the curriculum map.

{: .outline }
This page is an outline. The headings and points below show what it will cover.

## The description (ICP)

- What it teaches, what it needs first, what it leads to, and how demanding it is.
- It doesn't mention any curriculum, so it works with any of them.

## Matching it to a lesson

- Compare it with every lesson's description, keep the closest ten, and let a classifier pick one.
- Only trust the match when it's sure enough; otherwise keep the topic only.

## Why describe, not tag

- Descriptions still make sense when the curriculum changes.
- Two curricula can be linked through the same material.
