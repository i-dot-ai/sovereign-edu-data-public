# What's decided

{: .in-short }
The design decisions so far, and the reason for each.

{: .outline }
This page is an outline. The headings and points below show what it will cover.

## Decisions

- One pupil ID per school, from the school's system.
- Five kinds of record.
- Misconceptions judged at the end of a session.
- Answers kept in a standard store.
- Records never edited.
- A session's topic is a curriculum unit.
- Summaries rebuilt when a new report arrives.
- Six functions.
- Tools send records through the service.
- Materials come with their description.
- Unlabelled materials matched later.
