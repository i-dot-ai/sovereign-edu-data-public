# How to comment

{: .in-short }
Anyone with a GitHub account can comment on any page, suggest a change, or raise a bigger point.

{: .outline }
This page is an outline. The headings and points below show what it will cover.

## Ways to comment

- The comment box at the bottom of each page.
- "Suggest a change to this page".
- Raise an issue for a bigger point.

## How long comments are open

- A set time, then we update the document.
