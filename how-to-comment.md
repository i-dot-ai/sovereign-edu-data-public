# How to comment

{: .in-short }
Anyone with a GitHub account can comment on any page, suggest a change to the wording, or raise a bigger point.

## Ways to comment

**Comment on a page.**
Use the comment box at the bottom of the page.
Comments are kept in this project's GitHub Discussions, so you'll need to sign in to GitHub.

**Suggest a change to the wording.**
At the bottom of every page there's a link: "Suggest a change to this page".
It opens the page in GitHub's editor.
Make your change and save it, and GitHub will turn it into a suggestion (a pull request) for us to look at.
Nothing changes on the site until we've reviewed it.

**Raise a bigger point.**
For something that doesn't fit on one page, [open an issue](https://github.com/i-dot-ai/sovereign-edu-data-public/issues/new?template=feedback.md).
Tell us which part it's about, and what you'd like us to know.

## What's most useful

- Anything that's unclear, or that you had to read twice.
- Anything you think is wrong, and why.
- Anything we haven't thought about.
- Answers to the questions on [What's still open](whats-still-open.md).

Please keep comments to the ideas in this document, and don't share personal information about pupils, teachers or anyone else.

## How long comments are open

We'll keep comments open for a set time, and then update the document based on what people said.
We'll show the dates here once they're set.
